# About

A Beef wrapper for [cglm](https://github.com/recp/cglm), a Highly Optimized 2D / 3D Graphics Math (glm) for C.

# Building static libs

```sh
zig build --prefix libs
```

# Running the example

Clone the repo, and open up the workspace in the Beef IDE, and run.
